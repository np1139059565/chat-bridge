让AI从“应声虫”变成敢于反驳你的思考伙伴，核心在于**用提示词重构AI的底层行为逻辑**。以下基于实战研究整理了多份可直接复制的话术模板。

---

## 一、直言不讳的顾问型

这套提示词直接塑造AI的“人设”，强制其跳出讨好模式：

```
## 你的身份：
你是一位极度务实、直言不讳的顾问。你的唯一目标是帮我解决真正的问题，而不是让我感觉良好。

## 核心原则：
1. 禁止讨好：不要顺着我说，不要给情绪价值，不要说"你说得对"、"这个想法不错"之类的话
2. 直击要害：直接指出我的问题、盲点、逻辑漏洞
3. 区分事实与感受：如果我说的是主观感受，要求我提供客观事实
4. 挑战我的假设：质疑我认为理所当然的前提
5. 给结论不给安慰：告诉我该怎么做，而不是"你已经很努力了"

## 回应方式：
- 先指出我描述中的3个关键问题/盲点
- 追问我回避或没说清的关键信息
- 给出你认为我不想听但需要听的真话
- 最后给1-2个可执行的具体建议

## 禁止说的话：
- "你的想法很好，但是……"
- "我理解你的感受……"
- "这确实很难……"
- 任何先肯定后否定的句式

开场白："说事实，别说感受。我只帮你解决问题，不负责让你开心。"
```

**效果**：AI会直接指出“你的三个致命盲点”，追问具体数据（如“过去7天实际投入了多少小时”），而非给出一堆客套话。

## 二、反谄媚模式（系统级指令）

适合设置在系统提示词或用户偏好中，持续生效：

```
你的沟通原则：
1. 不要当应声虫——我说的话如果有问题，直接指出来，不要怕得罪我。永远不要用"很棒""很有潜力""很不错"这种空话敷衍我。如果你真的觉得好，要告诉我"好在哪"，不能只说好。
2. 挑战我的每一个想法——每次我提出一个想法，先找出最大的3个风险或漏洞。问我"你有没有想过……"来帮我发现盲点。如果我的方向错了，直接说"这个方向有问题"，不要绕圈子。
3. 给有用的反馈——不要只说"不好"，要告诉我"怎么改比较好"。用"这样做的风险是……，建议改成……"的格式回答。如果信息不够，直接问我，不要自己脑补。
4. 不要因为我反驳就放弃你的论点——停止过度肯定，转而质疑我的推理。
```

## 三、红蓝对抗式提问法

与其让AI“好好说话”，不如直接设定对抗框架：

**模板A——召唤“红队”攻击你**：
```
[背景信息] 我正在考虑做 [X]。
[红队指令] 停下。不要试图帮我完善这个想法，也不要试图讨好我。
我需要你扮演一个极度挑剔、专门找茬的反对者。请扫描我的观点，一旦发现任何漏洞、风险或逻辑问题，立刻进行无情的驳斥。
[真相验证] 如果你发现我的前提本身就是错的，直接告诉我："你在胡说八道"。
```

**模板B——全力反驳你的决定**：
```
我已經決定要做 [X]。請你用最強的論據，全力論證這個決定為什麼是錯的。不要客氣，把每一個可能的風險和反對理由都列出來。
```

## 四、双向钢人论证法

核心逻辑：让AI不仅支持你，还要用**最强形态**来反对你，杜绝AI为了讨好你而故意弱化反对意见：

```
请先别急着回答，用最完整、最有力的方式重述我真正想解决的问题。

然后使用钢人论证法，分别给出：
1. 支持我当前想法的最强证据
2. 反对它的最难被反驳的质疑

找出双方真正的分歧点，以及最可能改变结论的关键变量。

在给出判断前，只问我一个最关键的问题。等我回答后，再给出明确的判断、理由和下一步行动。
```

## 五、“失败优先”提问法（Failure-First）

强制AI在回答前先列“会失败的原因”：

```
在回答我之前，先列出什么会最快推翻/反驳我的论点。把你认为我的推理中最薄弱的地方全部列出来，然后再给出你的完整分析。
```

## 六、不确定性标签法

强制AI区分“事实”与“猜测”，避免编造：

```
为每一项主张添加标签：
- [KNOWN] 训练资料中的事实
- [COMPUTED] 计算得出
- [INFERRED] 推导得出
- [COMMON] 领域通用知识
- [GUESS] 没有依据的猜测

如果不知道，第一行必须写"我不知道"，不要编造答案。
```


## 核心设计原则（总结）

综合上述模板，要成功让AI“不迎合”，需把握以下原则：

**1. 提问方式决定一切**：用陈述句或确认性语气（“X是对的，对吧？”）提问时，AI的谄媚率最高；用真实问句（以“？”结尾）提问时，谄媚率显著降低。不要问“我的代码应该没有安全问题吧？”，要问“有没有边界情况或安全隐患？”。

**2. 去掉预设判断**：不要在问题中嵌入自己的倾向（“我觉得……，对吗？”），这等于把倾向性强塞进问题结构里，AI很难说“不”。

**3. 主动邀请负面信息**：用“有哪些问题”“最薄弱的地方”“反对者会说什么”这类措辞，从结构上绕开AI的默认顺从模式。

**4. 设定具体角色而非模糊指令**：与其说“请客观回答”，不如说“扮演一个痛恨伪科学的物理学家”。越具体的角色设定，AI越难滑向讨好模式。

**5. 警惕矫枉过正**：反谄媚指令可能让AI走向另一个极端——为了反对而反对，对每个观点都挑刺。建议在具体场景中要求它提供反面论证，而非设定笼统的“不要迎合”。

# R4 走查逐笔登记模板

## 一、用途

本模板定义合并逐笔对拍的登记列、每列填写口径、对拍判据与逐笔结论格式。逐项路径由分发方 R4 走查时按实仓逐笔登记，本模板不预填任何文件名。分母注记：23 = 3 实现 + 19 测试 + tunnel.cmd。

## 二、登记列定义（5 列，5/5）

| 列 | 名称 | 填什么 |
|---|---|---|
| 1 | 序号 | 逐笔登记的顺序号，从 1 起连续编号，与合入顺序一致 |
| 2 | 文件归属 | 该文件落在哪一侧：a 后端标准接口与会话、b 通道与协议字段、c 前端翻译员侧 |
| 3 | 对拍判据 | 按第四节四条判据给出本笔结论：直搬 / 本地化改写 / 不移植 |
| 4 | 实测分母 | 本笔实测的 pass / fail 条数与合计，分母逐笔可核 |
| 5 | 合入提交号 | 串行合入主线后回填的提交短号，未合入留待填 |

## 三、每列填写口径（5 条，5/5）

1. 序号：一笔一行，不跳号；补登记追加在表尾，不改写既有行。
2. 文件归属：按文件归属隔离口径填写，一侧只落一侧；跨侧文件在判据列注明。
3. 对拍判据：从第四节四条中取值，逐条给结论与证据位置，不写自述式完成结论。
4. 实测分母：写清分子 / 分母，例如 3/3；没查清写「没查清」，不编数。
5. 合入提交号：只认分发方串行合入后的提交短号；未合入时留空，不预填。

## 四、对拍判据（4 条，4/4）

1. 路径可解析：逐项路径由 R4 走查时按实仓登记，工程内相对路径可 git 解析；登记后复核分母。
2. 三态判定：同 blob 且归属一致记直搬；有差异需适配记本地化改写；主线已移除或重复记不移植，均附理由。
3. 归属隔离：a / b / c 三侧按队列隔离口径互不串文件；与 a 的「32 文件×3 树」矩阵分属两张表，不混填。
4. 分母复核：合计分母按 23 = 3 实现 + 19 测试 + tunnel.cmd 复核，逐笔累加后核总数。

## 五、逐笔结论写入格式（1 套，1/1）

逐笔结论由分发方验收后写入 docs/work-board.md 末节，格式如下：

    现行任务索引（一行式，细节按 commit 短号回 git log）
    | 序号 | 文件归属 | 对拍判据 | 实测分母 | 合入提交号 |
    |---|---|---|---|---|
    | 1 | R4 走查按实仓填 | 按第四节四条填 | 分子/分母 | 合入后回填 |

表头与列序固定；逐项路径与判据由 R4 走查时按实仓逐笔登记，不在本模板预填。与 docs/00-STATUS.md 进度表分开，不互相覆盖。

## 六、分母

登记列 5/5、填写口径 5/5、对拍判据 4/4、写入格式 1/1。合计分母 23 = 3 实现 + 19 测试 + tunnel.cmd，仅作注记；逐项路径清单尚未落盘，由 R4 走查登记后复核，与三仓树差异矩阵不混为一张表。

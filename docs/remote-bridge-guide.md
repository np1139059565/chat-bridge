# 远程桥接使用说明（QQ ↔ 网页 AI）

这份文档面向使用者，讲清楚怎么配置、怎么用、遇到问题怎么办。
设计细节见 `docs/remote-bridge-plan.md`。

---

## 一、这个功能能做什么

让你在手机 QQ 里，跟电脑上那个网页 AI 对话。人不在电脑前，也能：

- **看得见**：网页 AI 的回复一产生，就推到 QQ 上。
- **发得出**：在 QQ 里发的话，会自动送进网页 AI 输入框，等同于你亲手输入。
- **点得动**：用 `/css`、`/rtime` 这样的指令，远程清空会话、调整设置，甚至点击网页上的按钮。

一句话：**出门在外，手机就是你的键盘和监视器。**

---

## 二、开始前你要准备三样东西

**第一样：一个 QQ 机器人。**
去 QQ 开放平台（`q.qq.com`）注册一个机器人应用，拿到两个凭证：

- `AppID`：应用的身份证号。
- `AppSecret`：应用的钥匙。

这两个凭证填进设置页即可。机器人走官方 WebSocket 长连接，**你的电脑不需要公网地址，也不用内网穿透**。

**第二样：一个 Python 依赖。**
桥接层用 `websocket-client` 维持长连接。在 `flask_server` 目录下执行：

```bash
pip install websocket-client
```

没装也不影响其它功能——桥接只是不启动，会打印一行提示。

**第三样：抽屉保持开启。**
远程功能依赖抽屉在岗。**关掉抽屉，就代表你此刻不需要远程工作**，桥接会停止收发。
出门前记得让抽屉开着。

---

## 三、三步配置

### 第一步：打开设置

在网页 AI 页面点开抽屉，点右上角 ⚙ 图标进入设置页。

### 第二步：找到「远程桥接（QQ）」区块

点区块标题展开。你会看到：

- **启用远程桥接**：勾选框，加右侧连接状态指示灯。
- **AppID / AppSecret**：两个输入框。
- **保存并重启桥接**：按钮。

### 第三步：填写并保存

1. 勾上「启用远程桥接」。
2. 填入 AppID 和 AppSecret。
3. 点「保存并重启桥接」。

保存后，右上角指示灯变绿显示「● 已连接」，就成功了。

> 指示灯是「○ 未连接」时，看第八节「常见问题」。

---

## 四、怎么用

### 发消息

在 QQ 里直接给机器人发文字。它会自动包装成一条外部卡片，送进网页 AI。
网页 AI 看到的，跟你自己在电脑上输入完全一样。

### 看回复

网页 AI 每次**说完一整段**，桥接层就把新内容推到你 QQ。三类消息带不同前缀：

| 前缀 | 含义 |
|---|---|
| 👤 用户 | 网页对话里的用户消息 |
| 🛠 工具 | 工具调用 / 外部卡片 |
| 🤖 AI | 网页 AI 的回复 |

AI 回复里的**思考过程默认不推**（太啰嗦），需要时在设置页打开开关。
工具调用只推「调用了什么工具、参数是什么」，不推完整 JSON。

### 用指令

在 QQ 里发以 `/` 开头的消息，触发预设动作。详见下一节。

---

## 五、指令一览

| 指令 | 作用 |
|---|---|
| `/css` | 清空**所有**会话（消息 + 卡片），不可撤销 |
| `/cms` | 清空当前会话的消息列表（保留外部卡片） |
| `/csp` | 复制 System Prompt 并自动粘贴发送给 AI |
| `/rtime 秒数` | 修改自动回传延迟，如 `/rtime 5` |
| `/stime` | 切换自动回传开关 |
| `/sessions` | 列出会话列表（带序号、id、条数，当前会话标记） |
| `/ss 序号` | 按序号切换会话，如 `/ss 2` |
| `/screenshot` | 截取浏览器屏幕（保存到本地并回复路径） |
| `/help` | 显示指令列表 |

这些指令**开箱即用**，不用配置。

---

## 六、推送开关说明

设置页的「推送内容」有四个开关：

| 开关 | 默认 | 说明 |
|---|---|---|
| 用户消息 | 开 | 网页对话里的用户消息 |
| 工具消息 | 开 | 工具调用与外部卡片 |
| AI 消息 | 开 | 网页 AI 的回复 |
| 思考过程 | 关 | AI 的思考过程，通常很长 |

关掉某一类，那类消息就不会推到 QQ。

---

## 七、自定义指令（点击网页元素）

自定义指令让你**在 QQ 里点一下，就触发网页上的某个按钮**。比如把「发送」按钮绑成 `/send`，在外面临时补一句指令。

配置方式类似调试扩展的「选择元素」：

1. 在「QQ 指令」区块填**命令名**（含斜杠，如 `/deploy`）和**显示名**（如「部署」）。
2. 点「选择元素」按钮。
3. 到网页上点击你要绑定的那个按钮或元素。鼠标悬停时会高亮，点中后选择器自动回填。
4. 点「添加」，指令就生效了。

添加后，在 QQ 里发这个命令，抽屉就会去点击那个元素。

> 选择器由扩展自动生成（优先用唯一 id，否则沿 DOM 路径拼接），不需要你手写。
> 若按 Esc 或点「取消选择」可退出选择模式。

已有的自定义指令会列在下方，显示命令名、显示名和它绑定的选择器。每条提供两个按钮：

- **改选择器**：页面改版、按钮换了位置时用。点它进入选元素模式，重新点一个元素即可覆盖原选择器。
- **删除**：移除该指令。

### 点击失败会怎样

元素找不到、或选择器命中了多个元素时，**不会乱点**，而是在 QQ 里回复失败原因：

| 情况 | QQ 里的提示 |
|---|---|
| 找不到元素 | 「页面上找不到元素……页面结构可能已变，请重新选择元素」 |
| 命中多个 | 「该选择器命中 N 个元素，无法确定点哪个……请重新选择更精确的元素」 |
| 选择器无效 | 「选择器语法无效」 |

收到这类提示，用「改选择器」重新绑定即可。

## 八、常见问题

**问：指示灯一直「○ 未连接」怎么办？**

先说明：指示灯会在面板打开时每 5 秒自动刷新，连接成功后会自动转绿，不需要手动重开面板。

若持续不亮，按顺序排查：

1. 确认已 `pip install websocket-client`。
2. 确认 AppID / AppSecret 填对（注意别把 AppID 和 AppSecret 填反）。
3. 点一次「保存并重启桥接」。
4. 看 Flask 服务控制台，找 `[bridge]` 开头的日志。

**问：能让机器人显示「在线」吗？**

不能。QQ 官方 Bot API 没有设置在线状态的接口，机器人的在线状态由长连接自动决定——连上即在线、断开即离线。保持服务运行、连接正常，它就显示在线。

**问：QQ 发了消息，网页 AI 没反应？**

抽屉可能关着。打开抽屉再看。另外，QQ 消息进入网页 AI 后，是否自动发送取决于抽屉里的「自动」开关——没勾选时，卡片会停在抽屉等你手动发送。

**问：网页 AI 回复了，QQ 没收到？**

三种可能：

- 那类消息的推送开关被关了。
- 超过 60 分钟没在 QQ 发消息，窗口关闭了（见下条）。
- 抽屉关着。

**问：为什么过一段时间收不到推送了？**

QQ 官方规定：你发消息后 60 分钟内，机器人才能回复你。超过 60 分钟，窗口关闭，推送暂停。

**续期很简单：在 QQ 里随便发一条消息，窗口重新计时。** 你持续发消息，窗口就一直往后延。

## 九、当前限制

为免你踩坑，几条实话：

1. **QQ 接口字段待核对**：`qq_client.py` 里取 token、网关地址、发消息路径等标了 `[待核对]` 的位置，是按通行结构写的，接入前请对照 QQ 开放平台官网确认。若官方字段有出入，需要相应调整。
2. **截屏以文件形式返回**：`/screenshot` 目前把图片存到 `flask_server/screenshots/`，并在 QQ 里回复文件路径。要在 QQ 里直接看到图片，需接入 QQ 的媒体上传接口（多步且需平台权限），尚未实现。
3. **指令面板注册未落地**：`command_panel.py` 的 `register_panel` 目前只打印待注册内容，尚未发真实请求。内置指令通过在 QQ 里直接输入文字触发，不受影响。
4. **多页面不区分**：同时开着多个网页 AI 页面时，QQ 消息由当前打开着抽屉的那个页面取走。
5. **无发送者校验**：不限制谁能给机器人发消息。请自行保管好机器人。

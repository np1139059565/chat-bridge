# 手机 AI 接口 · 使用说明（v0.3）

## 这套东西是什么

把手机浏览器里的网页 AI，变成一个本地 AI 接口，让其它软件也能用。

两半组成：

- **QPython 服务**：对外提供标准接口，对内派活、收结果；
- **Firefox 扩展**：替你打字提问、等回答、抄回答案。

## 准备

1. 手机装好 **Firefox** 和 **QPython**；
2. 确保扩展已成功安装（能装的前提：zip 内 `manifest.json` 在根目录）。

## 第一步：启动 QPython 服务

1. QPython 新建 Python 文件，粘贴 `qpython_server.py` 全文；
2. 点运行，看到「手机 AI 接口服务已启动」；
3. 保持 QPython 在前台。

**验证服务活着**：浏览器打开 `http://127.0.0.1:8000/health`，应看到：

```json
{"ok": true, "pending_tasks": 0, "waiting_requests": 0, "active_leases": 0}
```

三个计数的含义：

| 字段 | 含义 | 正常值 |
|---|---|---|
| `pending_tasks` | 排队等扩展领取的任务数 | 空闲时 0 |
| `waiting_requests` | 正在等回答的外部请求数 | 空闲时 0 |
| `active_leases` | 扩展已领走、尚未回传的任务数 | 处理中应为 1 |

## 第二步：装新版扩展并启动接管

1. 解压新 zip，按之前成功的方式安装扩展；
2. 打开网页 AI（DeepSeek），右下角出现「AI Bridge」面板；
3. 点蓝色「▶ 启动自动接管」，显示「自动接管已启动」。

## 第三步：发一个测试请求

在 QPython 里另建一个文件，粘贴运行：

```python
import urllib.request, json

req = urllib.request.Request(
    "http://127.0.0.1:8000/v1/chat/completions",
    data=json.dumps({
        "model": "web-ai",
        "messages": [{"role": "user", "content": "用一句话介绍你自己"}]
    }).encode("utf-8"),
    headers={"Content-Type": "application/json"}
)

print("等待回答，最长 180 秒...")
resp = urllib.request.urlopen(req, timeout=200).read().decode("utf-8")
print(resp)
```

## 调试时怎么定位问题

按这个顺序看，能快速定位卡在哪一环：

### 1. 请求发出去后一直没反应

看 QPython 控制台：

- **完全没打印 `[HTTP] /v1/chat/completions`** → 请求没到服务，检查地址和端口；
- **打印了，但之后再无动静** → 任务在排队，扩展没来领。切到 Firefox 看面板是不是显示「自动接管已启动」。

### 2. 扩展领了任务但没回传

看扩展面板：

- 显示「📥 领到任务」但卡住 → 看后续有没有报错，多半是找不到输入框或发送失败；
- 显示「❌ 处理任务失败」 → 报错会原样传到调用方，那边能看到具体原因。

### 3. 调用方收到 502 错误

说明扩展明确失败了，错误信息里会带原因，例如：

- `网页操作失败：找不到输入框` → 用诊断项 0.3 检查；
- `网页操作失败：20 秒内未检测到新回答` → 发送没成功，用诊断项 0.4 检查。

### 4. 调用方收到 504 错误

两种情况：

- `等待扩展超时（180 秒）` → 扩展根本没来领，检查自动接管是否启动；
- `网页操作失败：扩展领走任务后超时未回传` → 扩展领走了但崩了，看扩展面板最后的输出。

### 5. 健康检查的三个计数能看出什么

| 现象 | 说明 |
|---|---|
| `pending_tasks` 一直大于 0 | 扩展没在领任务 |
| `waiting_requests` 大于 0 但 `active_leases` 为 0 | 任务还没被领走 |
| `active_leases` 为 1 持续很久 | 扩展正在处理，或已卡死（30 秒后会被清掉） |

## 当前能力与限制

**能做到**：

- 接收标准对话请求，转给网页 AI，按标准格式返回；
- 回答附带思考内容（字段 `reasoning_content`）；
- 返回 token 用量（**估算值**，响应里带 `note` 字段标明）。

**暂时做不到**：

- **不是真流式**：网页生成完才抓得到，一次性返回完整结果；
- **不能并发**：网页 AI 一次只能跑一个对话，多个请求排队；
- **QPython 保活**：切到后台可能被杀，服务中断。

## 安全提醒

- 服务只监听 `127.0.0.1`，外部设备访问不到；
- 当前不校验密钥，任何本机软件都能调。若将来要在局域网使用，必须先加鉴权。

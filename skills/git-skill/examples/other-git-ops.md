## 其他 Git 操作

### 常用 Git 命令

| 命令 | 说明 |
|------|------|
| `git status` | 查看工作区状态 |
| `git diff` | 查看未暂存的修改 |
| `git add <file>` | 添加文件到暂存区 |
| `git commit -m "message"` | 提交暂存区内容 |
| `git push origin <branch>` | 推送到远程仓库 |
| `git pull origin <branch>` | 拉取远程更新 |
| `git branch -a` | 查看所有分支(含远程) |
| `git checkout <branch>` | 切换分支 |
| `git merge <branch>` | 合并分支 |
| `git stash` | 暂存当前修改 |
| `git stash pop` | 恢复暂存的修改 |

### 其他 Git 相关命令

```cmd
git fetch origin
git log --stat
git difftool path
git branch -a
git stash list
```

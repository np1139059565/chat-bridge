> 可实测能力在 extend/lib/standard_chain_b9_slot_resolver.js 纯函数层。

## 一、全局不变量

- G1 STATUS 恒 declared-placeholder：清单/映射层与纯函数返回值均保持声明态。
- G2 唯一键恒标准 tool_call.id（call_<nonce>）与 tool 消息三键 role / tool_call_id / content，不含消息指纹。
- G3 活链文件零改动：五槽对应的协议包装层与公共解析层文件保持原样，不新增运行期探测分支。
- G4 异常违约不落盘：所有拒绝返回 persisted=false，纯函数不写全局状态、不写文件、不改入参。

## 二、逐槽三项（旧位所在层 → 替换位落点 → 实测断言）

### 槽位 M1｜bridge-chat-call

- 旧位所在层：前端消息信封与工具指令包装层。
- 替换位落点：信封字段 → 标准 tool_calls 意图位。
- 实测断言：旧位输入返回拒绝并附转换建议；新位输入返回规范化结果；异常输入返回不落盘拒绝。
- 对应槽位：S3；矩阵编号：#13；与 C-12 M1 对齐。

### 槽位 M2｜bridge-chat-res

- 旧位所在层：前端回执信封与结果合并层。
- 替换位落点：信封字段 → tool 消息三键位。
- 实测断言：同上三态。
- 对应槽位：S3；矩阵编号：#13；与 C-12 M2 对齐。

### 槽位 M6｜三网关包装

- 旧位所在层：三网关信封包装层。
- 替换位落点：包装层 → 标准信封字段位（三网关包装 → 公共层解析的落点类型条目）。
- 口径：按 docs/b6-legacy-caller-map.md「三网关 grep 零命中、通道侧指令走 command_dispatch 独立链路、
  external-call 三通道各自包装、解析全在公共层」，只在纯函数层做可断言条目。
- 实测断言：同上三态。
- 对应槽位：S3；矩阵编号：#13；与 C-12 M6 对齐。

### 槽位 M7｜公共层解析

- 旧位所在层：公共层解析与分发面。
- 替换位落点：解析层 → 标准 tool_calls / tool 消息三键位。
- 实测断言：同上三态。
- 对应槽位：S1 / S2 / S3；矩阵编号：#4 / #7 / #13；与 C-12 M7 对齐。

### 槽位 M8｜旧标记兼容位

## 通用三态判定口径

分发方对每条待对拍项在 B-7 到达时判且仅判一态：

- **一致**：b report 显式列出的字段面与 A-7 实交付、C-7/C-8 占位声明逐字段对齐，
  且无遗留活调用方、无标准键冲突 → 该项可转实装或保持现状，按分发方合入裁定。
- **待对拍**：b 未列全、留有兼容期暂留位、或该面依赖外部凭证 / 后续实装，
  证据不足以判一致或不一致 → 保持 `declared-placeholder`，补列后复判，不视为失败。
- **不一致**：替换位与标准 `tool_call.id` 及 tool 消息三键
  `role` / `tool_call_id` / `content` 冲突，或仍以旧协议字段 / 消息指纹为唯一键，
  或与 A-7 实交付签名冲突 → 定向裁定补正，不自动合入。

全局不变量（判据生效期间恒成立）：`STATUS` 仍为 `declared-placeholder`；
唯一键为标准 `tool_call.id`（`call_<nonce>`）与 tool 消息三键；
不把 adapter 装配到运行时 M、不建切换开关、不切活链、不代分发方判定时点。
